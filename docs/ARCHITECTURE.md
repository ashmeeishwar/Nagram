# Architecture

Plain React 18 + Vite, no router, no state library — state lives in `App.jsx` and
flows down via props.

## State model (App.jsx)

- `mode`: `'anagram' | 'unique'` — selected on the intro screen. Mirrored to a
  `data-mode` attribute on `.app` so CSS can tint the Unique-letters working area.
- `game`: `null` on the intro screen, else `{ letters, text, label, mode }`.
  - `letters` — the characters that become Line-1 slots (the name, or the reduced
    unique-CAPITAL letters in Unique mode).
  - `text` — what to display as the source (the original name / will statement).
  - `label` — `'Name'` or `'Will statement'`.
  - Rendering `<LetterGame key={game.letters} … />` — the `key` forces a fresh
    game when a new entry starts.
- `input`, `error` — the intro field + validation message.
- `theme`: `'dark' | 'light'` — persisted to `localStorage['nagram-theme']`;
  applied via `document.documentElement.dataset.theme` in an effect.
- `user`, `loginOpen`, `loginResolver` — placeholder auth.
  `ensureLogin()` resolves immediately if signed in, else opens the modal and
  resolves a promise when the user continues (or `null` on cancel).
- `savedOpen` — Saved modal visibility.

## Letter mechanic (LetterGame.jsx)

- `slots`: `Array.from(name).filter(c => c !== ' ')` → `{ char, id }`. Spaces in
  the source never become slots.
- `booked`: ordered tokens, each `{ kind:'letter', id, char, key }` or
  `{ kind:'space', key }`. Line 2 renders these left-to-right.
- Derived: `bookedLetterIds` (Set), `allLettersBooked` (Save gate, letters only),
  `lastIsSpace`, `canAddSpace` (= not locked && has tokens && last isn't a space).
- `collapseSpaces()` runs on removal so two spaces can never become adjacent.
- `handleSave()`: strip trailing space(s) silently → `await ensureLogin()` →
  `saveAnagram(sourceText, finalAnagram, mode)` → `saved` state.

## Theming (index.css)

- `:root` holds the dark palette by default. Light palette is applied by
  `:root[data-theme='light']` (explicit toggle) **and** by
  `@media (prefers-color-scheme: light) :root:not([data-theme])` (OS preference
  when the user hasn't chosen). Colors are all CSS variables; `--panel-unique`
  is the brighter tint used by `.app[data-mode='unique'] .intro/.game`.

## Art (sigilGeometry.js + components)

- All art lives in a `240×240` viewBox centered on `(120,120)`.
- `pt(angle, r)`, `seedOfLife(r)`, `polygon(sides, r, start)`,
  `starPath(points, r, step, start)` build the geometry; glyph `<path>`s from
  `devanagariGlyphs.js` are placed with `translate(x y) scale(size/1000)` (glyphs
  are centered on origin in 1000-unit em space, Y already flipped to SVG space).
- `scripts/generate-icons.mjs` re-implements the AppIcon as a plain SVG string
  (reusing the same glyph/geometry modules) and rasterizes via `sharp`.
